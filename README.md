# FREEDOM NUMBER · 自由半径

一个以「小Lin说」视频《你需要多少钱，才能财富自由？》的 **480× 法则**为蓝本设计的交互式财富自由计算器。

> **在线使用**：https://984607951.github.io/freedom-number/  
> **公开仓库**：https://github.com/984607951/freedom-number

## 功能

- **六种语言**：中文、English、한국어、日本語、Français、Русский
- **个性化计算**：月生活费、孩子数量与育儿成本、终身健康储备、重大资本开支、当前资产、每月投入、年龄、真实回报率
- **自由徽章**：根据结果生成「¥xxx 财富自由」纪念徽章，含五档自由等级
- **长期储蓄计划**：可交互的复利曲线、目标线、+20% 加速情景、10 年所需月投入与三阶段行动清单
- **分享卡**：一键生成 1080 × 1350 PNG，可下载、复制文案或调用系统分享
- **详细说明**：每个输入项都有通俗解释、参考值和数据口径；另附 6 篇计算手册与 6 个常见问题
- **人物视觉引导**：五种专属姿态——计算器抓头看手机、公式扛起家庭生活、手册盘腿阅读、问答惊讶捂嘴；计算器右栏另有一张写字海报作为视觉锚点
- **眼神联动**：桌面端人物虹膜跟随鼠标，手机端按固定节奏扫视；尊重系统“减少动态”设置
- **大号引言**：小Lin的引言放大成整块引用区，计算器右栏与表单底部对齐
- **输入提示**：输入框聚焦时以浅色示例值提示可填写内容，失焦自动恢复
- **暖色 A/B/C**：计算器分组标记改为暖橙/珊瑚色圆环，更容易定位
- **清晰大字**：更大的字号、更高的对比度、更短的说明，适合各年龄层阅读
- **明亮玻璃科技风**：极光渐变、网格背景、玻璃卡片与蓝/青/紫强调色
- **单文件版**：`index.html` 已内联 CSS、JavaScript 与全部人物图片，双击即可运行，不依赖同目录资源
- **无依赖**：纯 HTML / CSS / JavaScript，不需要后端或账号

## 公式

```
自由数字 = 月生活费 × (12 ÷ 实际回报率)
         + 单孩成本 × 孩子数量
         + 家庭终身健康储备
         + 重大资本开支
```

默认实际回报率 **2.5%**，乘数 = 12 ÷ 2.5% = **480×**。回报率可在 1.5%–3.5% 之间调整，乘数相应变化。

> 视频的严格假设：资产支付生活费之后，本金不缩水、购买力不下降。它比常见的 4% 法则更保守。

## 运行

直接双击 `index.html` 即可。它是**单文件版**：CSS、六语言文案和全部逻辑都已内联，不依赖同目录的 `app.js` 或 `styles.css`，因此从资源管理器、聊天附件或 U 盘打开都能正常运行。

如果浏览器仍然没有反应：

1. 使用最新版 Chrome、Edge 或 Firefox；确认浏览器启用了 JavaScript。
2. 按 `F12` 打开 Console，查看是否有红色报错。页面加载 2.5 秒后若脚本仍未启动，会显示内置的启动失败提示。
3. 如果文件来自聊天工具或网络下载，Windows 可能给它加上“来自其他计算机”的锁定：右键 `index.html` → 属性 → 勾选“解除锁定” → 应用。
4. 有些浏览器对 `file://` 脚本有限制，可以改用本地服务器：

```bash
cd freedom-number
python -m http.server 8080
# 打开 http://localhost:8080
```

部署时把整个目录上传到任意静态托管（GitHub Pages、Netlify、Vercel、Cloudflare Pages、对象存储等）即可，入口就是 `index.html`。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | **最终单文件版**，已内联全部 CSS / JS，可直接双击 |
| `src/index.html` | 模块化页面模板（引用外部资源） |
| `styles.css` | 视觉系统、响应式布局、动效 |
| `i18n.js` | 六语言文案（由 `i18n/*.json` 合并） |
| `app.js` | 计算、徽章、计划图表、分享卡 |
| `assets/*.webp` | 六张人物姿态素材，构建时已全部内联进 `index.html` |
| `build.mjs` | 将模板与资源打包成单文件 `index.html` |
| `i18n/*.json` | 分语言源文案，便于校对和修改 |
| `preview/*.png` | 首页、计算器、公式、手册、问答、结果、计划、分享卡预览图 |

修改源文件后，在项目目录运行：

```bash
node build.mjs
```

即可重新生成可双击的 `index.html`。

## 数据与隐私

- 不请求后端、不上传数据、不接入追踪脚本
- 语言与输入会保存在浏览器 `localStorage`，方便下次继续
- 页面中的货币换算使用演示汇率，仅用于多语言体验；真实规划请以当地货币与实际情况为准
- 育儿、医疗等参考值来自视频中引用的公开统计，主要基于中国内地数据
