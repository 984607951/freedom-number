# 财富自由计算器 · Freedom Number

> 没吃过猪肉，还没见过猪跑吗？那就一起来看看，你这辈子到底需要多少钱。

一个**打开就能用**的网页应用：用一条公式，把你自己的活法，算成一个属于你的数字。

不需要注册、不需要下载、不需要懂金融。滑动几个滑块，答案就出来了。

---

## 这是什么

你可能听过很多版本：

- 「500 万就够了吧？」
- 「在北京没个三千万别想」
- 「普通人还是老老实实上班吧」

**但那都是别人的数。**

这个工具做的事情只有一件：**把「我要多少钱才能不上班」这个问题，变成一个你能自己算出来的数**——用你的月开销、你的孩子、你的房子、你所在的城市。

算完你会得到一个大得吓人的数字。然后你会发现：真正让这个数字变小的杠杆，往往不是收益率，而是你欲望的形状。

## 为什么做这个

三个很朴素的理由：

**1. 那个数字，别人替你算不了。**
网上所有「财务自由需要 XXX 万」的说法，都是拿别人的生活水平套在你身上。月花 3000 和月花 3 万的人，答案差 10 倍。

**2. 它其实是一次人生规划。**
算这个数的过程，你被迫回答：我每个月想花多少？要不要孩子？想住在哪？这辈子到底要什么？——**这些问题的答案，比算出来的那个数字值钱得多。**

**3. 工具应该让人看得懂。**
市面上的理财计算器，要么塞满专业术语，要么把关键假设藏在折叠面板里。这个不是：**每个输入框下面都直接写着「该填什么、为什么填、填错了会怎样」**，字号大到眼睛不费劲，不用点开任何东西。

## 核心公式

```
财富自由临界值 = 480 × 月开销 + 单孩成本 × 孩子数 + 健康备用金 + 重大投入
```

那个 **480** 是全篇唯一需要动脑的地方：

```
真实收益率 = 名义收益率 4.5% − 通胀率 2% = 2.5%
乘数       = 12 个月 ÷ 2.5% = 480
```

意思是：**只要你有 480 个月的月开销，并且这笔钱每年能跑赢通胀 2.5%，你就永远花不完。**

- 月花 1 万 → 需要 480 万
- 月花 5 千 → 需要 240 万
- 今天的 480 块 = 往后余生每个月多出的 1 块钱

## 功能

### 🧮 计算器（四步）

| 步骤 | 你要填的 | 说明 |
|---|---|---|
| 1 | 月开销 | 吃穿住行、房租房贷、看病、娱乐、旅行、水电网。**不含**买房和养孩子 |
| 2 | 孩子数量 + 单孩成本 | 从怀孕养到 18 岁。全国平均 58 万，北京约 100 万，上海约 108 万 |
| 2 | 健康备用金 | 一辈子大病预留。二线 15–30 万，一线 30–60 万 |
| 2 | 买房 | 按理想房子的现价填。有房填 0，租房就把月租加进第 1 步 |
| 3 | 收益率 + 通胀率 | 银行定存只有 0.95%，普通人合理配置约 4%~4.5% |

**实时反馈**：右侧结果卡片始终可见，任何一个数字变动，总额、构成拆解、进度条立刻跟着变。

**构成拆解**：不只给你一个总数，还告诉你这 770 万里，多少是「日常生活」、多少是「养孩子」、多少是「看病」、多少是「买房」。

### 🪙 财富自由徽章

算完可以生成一枚**只属于你的徽章**：

- **6 个等级**：轻装 → 起步 → 城市 → 从容 → 一线 → 星耀（按金额自动判定）
- **唯一编号**：由你的计算结果生成（如 `FN-27786`），同一个数字永远是同一个编号
- **签发日期**：记录你算出这个数字的那一天
- 徽章是 SVG 实时绘制的，不是图片，任何分辨率下都清晰

### 📤 分享海报

一键生成 **1080 × 1440** 的分享图（横幅比例，适合朋友圈/小红书/微博）：

- 自动包含徽章、金额、构成明细、乘数
- 支持**保存图片**、**系统分享**（手机端调起原生分享面板）、**复制到剪贴板**

### 📈 储蓄计划曲线

知道「需要 770 万」之后，下一个问题必然是「那我什么时候能到」。

- 输入每月能存多少、每年多存多少
- 自动画出**从今天到达成**的复利曲线，标出目标线和达成点
- 如果 60 年都到不了，它会**反过来算**：按 30 年达成，你每月需要存多少钱
- 显示累计投入 vs 投资收益——让你直观看到「时间比收益率更值钱」

### 📖 公式拆解

用大白话讲清楚 480 从哪来，配四张原理解释卡：

- 为什么是 480 倍？
- 为什么不能只存定期？
- 孩子、生病、房子为什么要单算？
- 它其实是一次人生规划

### 📘 计算手册

四步照着填，专治「不知道这个格子该填什么」。比如第一条就告诉你：**把最近三个月的生活费加起来除以 3**，就是你的真实月开销，不用精确到个位。

### ❓ 常见问题

算完数字太大必然会问的那几个问题，直接给答案：

- 算出来一千多万，是不是这辈子没戏了？
- 为什么月开销 1 万就要 480 万？
- 我有房子，还要填买房钱吗？
- 4.5% 的收益率靠谱吗？
- 这个数字以后会变吗？

### 🌍 五种语言

中文 / English / 한국어 / Français / Русский

不只是界面翻译——**所有说明文案、数据引用、徽章文字、海报文字**都完整本地化，数字格式也按语言切换（中文用「万/亿」，其他语言用 K/M/B）。

## 技术栈

**零依赖，零构建。**

| 项目 | 说明 |
|---|---|
| HTML | 单页，语义化结构 |
| CSS | 原生 CSS，玻璃拟态 + CSS 变量主题 |
| JavaScript | 原生 ES6+，无框架无打包 |
| 徽章 | 运行时生成 SVG |
| 海报 | Canvas 2D 绘制 |
| 图表 | 运行时生成 SVG + 描边动画 |

**为什么不用框架？** 因为这个应用的全部逻辑就是「几个输入 → 一个公式 → 一个数字」。引入 React + 构建链，会让打开速度变慢、部署变复杂，而收益为零。

**体积**：3 个代码文件，约 2800 行，加上 6 张人物素材，整站不到 1 MB。
